# SafeCheck

AI-powered digital safety copilot.

## Current Scope

- Live Gmail email monitoring and analysis
- Document/PDF analysis
- URL analysis
- Deterministic risk assessment
- Evidence-based explanations
- Safety Circle and recovery guidance

## Project Structure

- `backend/` — FastAPI backend, analyzers, workflow, risk engine, and integrations
- `web/` — Next.js frontend
- `docs/` — API contract, architecture, demo, and limitations

## Status

Project initialization in progress.
